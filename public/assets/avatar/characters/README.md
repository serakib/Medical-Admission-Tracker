# Character Preset SVGs

এখানে Avatar Builder-এর ২০টি সম্পূর্ণ character preset-এর standalone editable vector SVG আছে।

- `m01.svg`–`m10.svg`: পুরুষ Character Preset
- `f01.svg`–`f10.svg`: নারী Character Preset

Artwork path প্রতিটি SVG ফাইলের ভেতরে embedded; remote image/API reference নেই। SVG text/vector editor-এ খুলে সরাসরি edit করা যায়। Reusable parts-এর জন্য পাশের `hair/`, `eyes/`, `eyebrows/`, `mouths/`, `clothing/`, `accessories/` folder ব্যবহার করো।

Source: Avataaars by Pablo Stanley; see `../../ASSET-CREDITS.md`.

**Runtime note:** এই preset files self-contained local vectors। Avatar Builder-এর live customization renderer এখনও DiceBear API URL তৈরি করে; তাই পুরো Builder-কে offline/local-only করতে renderer migration আলাদা করে প্রয়োজন।
