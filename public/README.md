# Public files

এই folder-এ browser থেকে সরাসরি load হওয়া static public files রাখা হয়।

## Folder contents

- [assets/](./assets/) — website-এর favicon, illustration ও অন্যান্য static visual assets।
- [assets/README.md](./assets/README.md) — asset list, path convention, source ও license update করার নিয়ম।

## নিয়ম

- শুধু browser-এ প্রকাশযোগ্য file এখানে রাখবে।
- Password, private key, API secret, access token বা ব্যক্তিগত user data এখানে রাখবে না।
- নতুন asset যোগ করার আগে source ও license যাচাই করবে এবং প্রয়োজন হলে asset credit update করবে।
- HTML/CSS/JavaScript-এ asset path ব্যবহার করার সময় GitHub Pages-এর relative path ঠিক আছে কি না পরীক্ষা করবে।
