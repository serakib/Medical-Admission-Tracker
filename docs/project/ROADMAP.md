# Roadmap

This roadmap describes possible project priorities, not guaranteed features or delivery dates. Work may change based on student feedback, reliability, available time and the requirements of the relevant admission cycle.

## Current priorities

- Maintain reliable practice, timed exams, result calculation and question review.
- Improve correctness and consistency of profile, XP/RP, rank and leaderboard data.
- Improve mobile usability, accessibility and Bangla-language clarity.
- Strengthen account privacy, backend authorization and safe handling of student data.
- Keep question-bank metadata, explanations and source information accurate.

## Next areas to evaluate

- Better filtering and progress summaries across subjects, years and question sources.
- More useful review workflows for incorrect, unseen and bookmarked questions.
- Clearer diagnostics and recovery guidance for account, sync and network errors.
- Automated checks for question-bank structure, documentation links and frontend regressions.

## Longer-term possibilities

- Expanded student-facing study guides and preparation analytics.
- Additional accessibility improvements informed by real user feedback.
- More maintainable separation of frontend modules and backend responsibilities.

## Suggest or discuss an idea

Use the [Feature Request issue form](https://github.com/serakib/Medical-Admission-Tracker/issues/new?template=feature_request.yml). Please describe the student problem the idea solves. No item has a promised release date unless a specific release plan says otherwise.
