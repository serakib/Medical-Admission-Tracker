# Question Bank Guide

- `questions.json` is the single source of questions.
- Subject values are normalized to: `biology`, `chemistry`, `physics`, `english`, `gk`.
- Authentic previous-year questions supplied with the project are preserved.
- Additional questions added in this update are labeled `year: "Practice"` and `source: "Medical Admission Practice"`; they are original practice questions, not claimed as official past papers.
- To add more authentic previous-year questions, use questions you own, have permission to republish, or provide as source material.
- The UI can filter by subject and year without changing HTML/JS.
