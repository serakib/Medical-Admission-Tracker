# 💬 Support & Contributing

Project-এ feedback, bug report ও improvement suggestion স্বাগত—তবে student privacy এবং repository security বজায় রাখতে হবে।

## Support options

|---|---|
| Website ব্যবহার শেখা | [Getting Started](Getting-Started) |
| Bug report | [Bug Report Form](https://github.com/serakib/Medical-Admission-Tracker/issues/new?template=bug_report.yml) |
| New feature idea | [Feature Request Form](https://github.com/serakib/Medical-Admission-Tracker/issues/new?template=feature_request.yml) |

## Helpful bug report

একটি ভালো bug report-এ থাকবে:
- Affected page বা feature।
- Problem reproduce করার steps।
- Actual result এবং expected result।
- Browser ও device details (যদি relevant হয়)।
- Redacted screenshot বা error message (যদি relevant হয়)।

Password, Firebase token, student record বা অন্য sensitive information share কোরো না।

## Contribution rules

1. Existing issue/documentation search করো।
2. বড় change-এর আগে issue খুলে maintainer feedback নাও।
3. এক pull request-এ একটি focused change রাখো।
4. কীভাবে test করেছ তা লেখো; test না করলে স্পষ্টভাবে উল্লেখ করো।
5. UI change হলে relevant desktop/mobile screenshot দাও।
6. Accessibility, privacy ও backward compatibility বিবেচনা করো।
7. Pull Request Template-এর checklist পূরণ করো।
