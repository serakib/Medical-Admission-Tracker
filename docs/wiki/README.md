## 🌐 GitHub Wiki-তে ব্যবহার

Repository-র Wiki feature enabled। এই folder-এর Markdown pages-গুলো Wiki-তে publish করার জন্য প্রস্তুত। GitHub-এর Wiki editor ব্যবহার করে Home page ও অন্যান্য topic page তৈরি করো; Sidebar ও Footer-ও আলাদা Wiki page হিসেবে ব্যবহার করা যাবে।

GitHub Wiki page তৈরি/সম্পাদনার নির্দেশনা:
https://docs.github.com/en/communities/documenting-your-project-with-wikis/adding-or-editing-wiki-pages

বর্তমানে এই folder-টাই documentation source hub; actual Wiki page-এ publish করার পর Wiki tab থেকেও একই guide পড়া যাবে।
