# 🚀 Getting Started

এই guide নতুন শিক্ষার্থীদের Medical Admission Pro ব্যবহার শুরু করতে সাহায্য করবে।

## 1. Website খোলো
[Medical Admission Pro](https://serakib.github.io/Medical-Admission-Tracker/) website-এ প্রবেশ করো। Mobile ও desktop—দুই ধরনের screen থেকেই ব্যবহার করার জন্য interface তৈরি করা হয়েছে।

## 2. Account নির্বাচন
- **Guest Account:** দ্রুত practice শুরু করার জন্য।
- **Registered Account:** Firebase Authentication দিয়ে নিজের registered account ব্যবহার করার জন্য।

Guest session-এর পরিচয় browser-এ রাখা token-এর সঙ্গে যুক্ত। Browser storage clear করলে বা অন্য device ব্যবহার করলে Guest session পুনরুদ্ধার করা কঠিন হতে পারে। গুরুত্বপূর্ণ progress দীর্ঘমেয়াদে রাখতে registered account ব্যবহার করো।

কখনো password, verification code বা authentication token অন্য কাউকে দেবে না।

## 3. Practice শুরু
- **Question Bank:** প্রশ্ন খুঁজে পড়া ও filter করা।
- **Practice Lab:** নিজের গতিতে solve করা এবং ভুল review করা।
- **Exam Mode:** নির্ধারিত সময়ের মধ্যে test দেওয়া।

## 4. Result review করো
Exam শেষে score, correct, wrong, unanswered এবং available subject-wise analysis দেখো। শুধু total score নয়—যে topic-এ ভুল হচ্ছে সেটিও review করো।

## 5. Progress track করো
Profile-এ available exam history, XP, RP, rank ও streak information দেখো। Leaderboard-এ নিজের position ও বন্ধুদের progress দেখতে পারো।

## ভালো অভ্যাস
- প্রশ্নের explanation থাকলে সেটি পড়ো।
- ভুল উত্তরগুলো আবার solve করো।
- একই exam বারবার submit কোরো না; result আটকে গেলে আগে history ও profile refresh করে দেখো।
- Admission preparation-এর official syllabus ও circular-এর সঙ্গে নিজের পড়াশোনা মিলিয়ে নাও।

কোনো সমস্যা থাকলে [FAQ & Troubleshooting](FAQ-and-Troubleshooting) দেখো অথবা [Bug Report form](https://github.com/serakib/Medical-Admission-Tracker/issues/new?template=bug_report.yml) ব্যবহার করো।
